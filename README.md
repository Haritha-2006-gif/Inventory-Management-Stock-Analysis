# Inventory Management & Stock Analysis Dashboard

## Project Overview
Developed an interactive Inventory Management and Stock Analysis Dashboard using Microsoft Excel to monitor inventory levels, analyze sales performance, track stock availability, and support data-driven business decisions.

## Project Objectives
- Monitor total inventory and stock availability.
- Analyze inventory value across product categories.
- Track units sold and inventory performance.
- Identify low-stock and out-of-stock products.
- Analyze inventory distribution across suppliers.

## Tools & Technologies
- Microsoft Excel
- Excel Tables
- PivotTables and PivotCharts
- Excel Formulas
- Conditional Formatting
- Interactive Slicers
- Data Visualization

## Key Features
- KPI cards for total products, inventory value, units sold, low-stock items, and out-of-stock items.
- Inventory value analysis by category.
- Stock status distribution.
- Sales analysis by product category.
- Supplier-wise inventory analysis.
- Top 5 products by inventory value.
- Interactive filtering using slicers.

## Data Analysis Process
1. Prepared and organized the inventory dataset.
2. Applied calculated columns and Excel formulas.
3. Created PivotTables for category, supplier, sales, and stock analysis.
4. Developed interactive charts and KPI cards.
5. Added slicers for dynamic filtering.
6. Designed the final dashboard to communicate business insights.

## Key Learnings
- Practical application of Excel for data analytics.
- Inventory and stock performance analysis.
- Data visualization and dashboard development.
- Converting raw data into meaningful business insights.
